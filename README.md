# ちゃっと小テスト 1.7.1

Delta Chat のチャット内で使う webxdc アプリです。小テスト、理解度アンケート、無記名投票、出席確認、宿題状況の確認を行えます。

## はじめ方

1. `chatto-shotest-1.7.1.xdc` を Delta Chat のクラス用チャットで共有します。
2. 先生・生徒が同じチャットでファイルを開き、初回設定で役割と表示名を選びます。先生は配布前に管理者登録し、確認番号を黒板など別の方法で生徒へ示します。
3. 先生は完成問題集、空テンプレート、AI補助作問のいずれかで問題を用意します。
4. 内容を確認して配布し、生徒が回答した後、集計グラフを確認します。

## 主な内容

- 完成済み問題集：65セット・315問（短答60問・複数選択等15問を含む）。学校段階・学年・教科・単元で検索できます。教科書会社タグは先生が教材を照合して付ける端末内メモで、公式準拠を示しません。
- 問題形式：4択、複数選択、○×、記述・短答、ならべかえ、言葉パズル。
- AI補助作問：4段階ウィザード。依頼文・回答の受け渡しは手動コピー＆ペーストです。自動入力・自動配布はしません。エッジAIの初期URLは空欄です。学校で使えるURLを先生が設定してください。外部AIはChatGPTが初期値です。
- 授業活動：理解度アンケート、無記名投票、出席確認、宿題状況。
- 分析・管理：問題別正答率、生徒別単元レポート、クラス平均との差、回答時間、40%未満の生徒への再テスト、問題・解答印刷、CSV出力、管理者バックアップ。クラス名（例：1年1組）も設定できます。

## 大切な仕様

- 配布する小テストには正解・キーワード・解説が含まれ、生徒端末にも届きます。形成的評価・練習用として使ってください。厳密な試験には向きません。
- 無記名投票は回答に氏名・出席番号を含めませんが、グループ内の対象外ユーザーも投票でき、完全匿名・厳密な一人一票を保証しません。集計は参考値です。
- 出席・宿題状況は本人の申告です。正式な出席簿や宿題ファイル回収ではありません。
- CSVやバックアップは個人情報を含むことがあります。保存・送信先に注意してください。
- 回答時間は操作していない時間も含む場合があり、参考値です。成績個票・クラス分析は提出済み記録の参考資料です。
- 1つのwebxdcは1つのクラスチャットで利用してください。複数学級の一括管理や教員間で共有する問題バンクはありません。TinyBoxのCGIは作問依頼用で、共有保管APIには接続されていません。
- 通信遅延があり、結果は常に即時更新とは限りません。実際のクラスで使う前に小規模な動作確認をしてください。
